SBN Savings Bond Ritel SBR015 menjadi investasi yang menarik di tengah ketidakpastian arah suku bunga, karena ada return (kupon) floating with floor: Jika BI Rate naik, maka return SBR015 otomatis akan ikut naik. Jika BI Rate turun, return tidak akan turun dari batas minimumnya.
